# 管理指南

建立地圖、開放投稿與後台操作。部署見 `deploy.sh --help`，擴充見 [EXTENDING.md](EXTENDING.md)，嵌入見 [EMBED-API.md](EMBED-API.md)。

## 建立一張地圖

以主要 PIN 登入後開 `<base>/newproject`，填標題、拖曳標記定位即可。也可手動在 `projects/<id>/` 放 `meta.json`，不必改程式：

```json
{ "id": "mymap", "title": "我的地圖", "subtitle": "副標",
  "center": [23.95, 120.69], "zoom": 14,
  "numbering": "suffix", "categoryOrder": ["green", "pink", "blue"] }
```

- `meta.json` 放標題、中心點、分類順序與模組開關（`features`）；投稿要不要碼由後台的投稿代碼決定。
- 點位存在 `projects/<id>/spots.jsonl`，由後台或「建立」視窗新增（唯讀地圖不提供）。
- 網址：地圖 `<base>/<id>`、首頁列出所有地圖、後台 `<base>/manager`。

## 開放投稿

- **碼即開關**：建立有效的投稿代碼就是開放投稿（要碼才能投）；沒有有效碼＝未開放，只有管理者能投。
- 碼存於 `projects/<id>/codes.json`，可同時多組，各自可設到期時間與使用上限。
- 後台一碼一張卡：邀請連結（`<base>/<id>?code=XXXXXX`，一點即解鎖）、QR、用量、刪除。
- 投稿對話框可單獨嵌入，見 [EMBED-API.md](EMBED-API.md)。
- 猜錯代碼有獨立限流，可在 `rate_limits.codefail` 調整。

## 管理後台

- 進入：`<base>/manager`，或在地圖頁連點標題、首頁連點 logo 叫出 PIN 面板；登入狀態用 httpOnly cookie 保持。單張地圖在 `<base>/manager/<mapid>`。
- 權限可逐專案、逐項授權，PIN 與帳號皆可使用；架構見 [EXTENDING.md](EXTENDING.md) 第十三章。
- 功能：投稿代碼與身分管理、統計、審閱與刪除投稿、備份與還原（ZIP）、主題包與圖層管理、資料修復工具。

## 內容顯示與署名

在專案設定的「內容顯示」，點位與投稿的編輯紀錄、署名各有獨立開關，預設均開啟。開關控制前台顯示，既有版本紀錄仍保留，管理與寫入權限不變。

署名格式支援 `{name}`、`{datetime}`、`{date}`、`{time}`，可換行，內容以純文字顯示。點位預設為 `— {name}・{datetime}`；投稿預設姓名與日期時間分兩行。留空恢復預設，最長 500 字元。格式存於 `meta.bylineFormats.spot`／`entry`，顯示開關沿用 `features.spotHistory`／`entryHistory`／`spotByline`／`entryByline`。

左上控制面板預設寬 280px，最小寬 220px，窄螢幕會限制在畫面寬度扣除兩側 14px。點位清單數量使用膠囊顯示；點位介紹直接呈現內容，不再加上固定標題。

驗證：`php tools/checkall.php`；`node tools/displaycheck.js`（需 Playwright／Chromium，使用隔離資料與模擬地圖引擎，驗證後台儲存與前台顯示）。

## Font Awesome 地標圖示

專案設定 → 地標外觀 → 地標顯示選擇「Font Awesome 圖示」。`pinMark` 的 `number`／`blank`／`shape`／`image`／`icon` 互斥，圖示模式只顯示圖示，標題編號仍由 `numbering` 獨立決定。

同一類別共用 `meta.categoryIcons[類別代號]`，無分類使用 `new`。選單有即時 SVG 預覽，名稱只接受內建的 61 種免費 Solid 圖示（Font Awesome Free 6.5.1），未設定或非法名稱退回 `location-dot`。背景仍使用既有 `categoryColors`，尺寸、外框、投稿徽章及音訊播放光暈不變。切換其他模式會保留圖示設定供日後使用。

圖示來自官方 `@fortawesome/free-solid-svg-icons@6.5.1`，固定 SVG 路徑存於 `assets/icons/fontawesome-solid.json`，授權附於同目錄的 `FONT-AWESOME-LICENSE.txt`。僅啟用 icon 模式的地圖載入圖示目錄與渲染工具，不依賴 Font Awesome 字型下載。

導航按鈕的圖示放大至 20px，按鈕仍維持 32×32px；導航選單與點位面板的關閉／展開圖示也調整清晰度，按鈕尺寸不變。

點位下拉清單的數量顯示在選擇框內；展開清單沿用主題樣式並限制高度。專案設定的「功能模組」可切換「清單顯示地標」（預設開啟），清單標記沿用地圖的模式、尺寸與類別顏色。未開放投稿時不顯示邀請第一則投稿的空白提示；既有投稿仍可瀏覽。

文字與圖片投稿的說明均支援 Markdown，沿用伺服器端的 `spot_markdown()` 解析；原始說明仍儲存在 `comment`，HTML 僅在回傳時產生。圖片的投稿卡片及放大預覽都會呈現 Markdown。CC BY 投稿顯示「CC BY · 作者名稱」，使用投稿的 `name` 欄位，包含匯入作者；授權姓名標示不受投稿署名顯示開關影響。

投稿授權使用 `license` 欄位：`cc0`、`cc-by`、`cc-by-sa`、`cc-by-nd`、`cc-by-nc`、`cc-by-nc-sa`、`cc-by-nc-nd`。有身分或填寫署名的新投稿預設選 CC BY-SA，不必註冊；沒有身分且未署名時使用 CC0。保留既有記憶選項及歷史授權。`author_url` 為選填作者網址（http／https）；匯入資料可使用相同欄位，授權者使用原始投稿的 `name`。授權標章連到官方說明，複製連結顯示在同一列左側。投稿條款見 PRIVACY.md。點位下拉清單使用浮動彈出層，不改變控制卡高度。

投稿末尾的操作與授權共用一列，空間不足時自然換行。「引用」圖示可複製作者與授權名稱，以及原始投稿的分享連結；授權條款網址由旁邊的標章提供。


### 精選投稿星章

管理模式下，投稿卡片右上角顯示灰色圓形底、白色星星。具備「管理投稿」權限的管理員可以點擊設為精選，再點一次取消；操作不改變照片、文字、點位配對或排序。訪客只看得到精選投稿的彩色星章，不會看到未精選的灰色按鈕。

專案外觀設定可調整「精選投稿星章底色」，預設暖黃色 `#d6a52a`，只接受六位十六進位色碼。既有專案不會自動精選任何投稿；沒有 `featured` 欄位時視為未精選。狀態保存於原始投稿的 `featured` 布林欄位，投稿編輯版本沿用原始狀態。QR／投稿深層連結的短暫青綠色外框高亮維持原樣。

接口：`POST ?api=featureentry`，欄位為 `project`、原始投稿 `id`、`featured`（`1` 或 `0`）及管理者 `csrf`。只接受具備 `manage_contrib` 權限的管理者，投稿者本人不能僅靠投稿代碼或擁有者憑證設定精選。

精選投稿會在所屬點位旁顯示預覽，取代該點位的投稿數字角標。最多顯示三則，其餘以「＋數量」開啟點位面板；文字與沒有封面的媒體使用型別圖示。點擊圖片或媒體預覽可開啟完整內容，文字圖示開啟點位面板。沒有 GPS 也可顯示，預覽固定分布在地點四周，依可用空間減少預覽，並以細線辨識所屬地點；空間不足時收合為「＋數量」，完全放不下則保留地點的投稿數量角標，點擊仍可查看全部投稿。放大後重新展開。只使用畫面像素偏移，不修改投稿座標。縮放小於 14 時為 14px 小方塊，14 至未滿 16 時為 22px 縮圖，16 以上為 32px 縮圖；環繞距離同步調整，沿用既有緩動過渡，偏好減少動態效果時停用動畫。關閉投稿顯示時一併隱藏。未精選的 GPS 投稿仍沿用「投稿」模式顯示。未配對點位的精選投稿不產生點位旁預覽。星章圓底為 26px、星星為 20px，操作範圍保留 32px。

投稿視窗的授權與署名並排，窄螢幕自然改為上下排列。授權附有白話說明；個人連結預設收合，可填個人網站、社群或聯絡頁面，不作為身分驗證。批次中的「個別署名」預設收合，需要時可調整；無身分且個別項目也未署名時，該筆使用 CC0。建立點位與投稿共用表單樣式，內容只使用一個捲動區，送出操作保留在底部。

可使用 `php tools/contributioncheck.php` 驗證投稿與授權 API，以及 `node tools/contributionuicheck.js` 驗證手機／桌面與深淺色投稿、建立點位視窗。兩者只寫入隔離暫存專案，前端測試以模擬地圖引擎保留真實投稿 API。

Markdown 說明使用輸入區旁的精簡問號圖示，不另外佔一列；個別署名收合使用 Font Awesome 方向圖示。投稿、建立點位與點位文字編輯共用同一個說明視窗。常用與更多語法提供寫法／顯示效果對照，範例沿用伺服器 Markdown 解析器；不宣稱支援任意 Markdown 擴充。說明使用原生 dialog，Escape 只關閉說明並恢復觸發按鈕的焦點。個人連結收合入口使用 Font Awesome 連結與方向圖示；定位來源與還原定位共用一個可換列操作區。

投稿／建立點位視窗的內容順序為主要內容、關聯點位／定位、個別署名與個別送出，之後確認共用署名與授權。個別送出採次要樣式；底部依未完成項目數顯示「送出這則／建立點位」或「全部送出」。空佇列、檔案準備中與全部成功後停用送出，失敗項目保留可重試。批次進行中鎖定共用授權與署名，避免同一批在途中換設定；不重複送出完成項目。建立點位不讀取投稿專用的個人連結或授權選項。開啟視窗聚焦內容操作，Tab 留在視窗內，關閉後回到觸發按鈕。

地圖只建立畫面及周圍 96px 緩衝範圍內的投稿預覽；移出範圍後卸除，移回時恢復。拖曳期間沿用原標記，移動結束或視窗尺寸改變後才重排；相同視角不重算。篩選投稿者時，數量角標也包含沒有 GPS 的投稿。

### 目前位置

「回到地圖初始位置」上方的導航箭頭按鈕可顯示目前位置。預設啟用，管理者可在專案設定的「功能模組」關閉「目前位置」（`features.locate`）。載入頁面不自動定位，點擊才透過瀏覽器請求定位權限；成功後顯示藍色位置標記並移動地圖，再次點擊更新位置。

需要 HTTPS 與瀏覽器定位支援。若曾拒絕權限，瀏覽器可能不再詢問，需在網站設定允許定位後重試。定位逾時或無法取得位置會提示原因，按鈕可再次操作。座標不寫入投稿或資料庫；底圖請求仍會依移動後的視角載入圖磚。

### AAC 音訊上傳

支援純 `.aac` 與既有 `.m4a` 音訊。實際檔案類型由伺服器的 fileinfo 檢查，不採信瀏覽器宣告的 MIME。有 FFmpeg 時，純 AAC 優先直接封裝成 M4A，不重新編碼、不受音訊壓縮開關或檔案大小門檻影響，也不要求結果更小；既有 M4A 與其他音訊沿用原有處理。

若 FFmpeg 不可用、封裝逾時或失敗，仍接受 AAC 原檔；部分瀏覽器可能無法播放純 AAC。部署時檢查 PHP CLI 是否可執行設定的 `ffmpeg_bin`。Debian／Ubuntu 的互動部署在缺少工具時詢問是否立即安裝，確認後執行 apt 更新與安裝，再重新檢查；已安裝不重複安裝。非 root 需要 sudo，非互動部署與其他系統提供手動安裝指引。安裝失敗不阻擋原檔上傳。

PHP-FPM 也必須可執行 FFmpeg（`proc_open`、程式路徑與權限）；CLI 檢查不代表網站 PHP 的執行環境完全相同。小檔案的換容器可能略增大小，這是為了播放相容性，不是壓縮。

### 類別名稱與部署權限

地點詳情及分類圖例使用 `catLabel` 顯示名稱；未設定、空白或舊版無分類預設 `new`／「新增點位」時，顯示專案 `meta.title`。分類識別碼、篩選、顏色與 icon 不變；圖例仍由原有模組開關控制。

`./deploy.sh` 預設修復 `projects/`、`state/` 與 `api/config.php` 的權限，優先辨識 PHP-FPM 執行帳號。可用 `--fix-perms-only` 單獨修復；自訂帳號可設 `DEPLOY_WEB_USER`。權限修復失敗會停止部署，不回報成功。

投稿的連結、引用、編輯、歷史與刪除使用同一操作列；各項仍依權限及功能開關顯示。地點內容編輯與位置調整使用附文字提示的 icon 按鈕。

### 地標自訂色與初始取景

在地點編輯介面取消「沿用分類顏色」即可選擇獨立地標色；重新勾選會清除自訂色。顯示依序使用地點 `markerColor`、分類色與預設色；既有分類紀錄的 `color` 仍作為分類色回退。儲存使用既有版本紀錄，不改寫起點。

後台「初始取景」可選「專案設定」（預設，使用 `meta.center`、`meta.zoom`）或「自動取景」（全部點位的 `fitBounds`），以 `meta.initialView` 的 `meta`／`fit` 儲存。載入及回到地圖中心會遵守此模式；嵌入網址明確指定 `view` 時仍優先使用嵌入設定。既有專案未設定模式時使用專案設定。

前台操作按鈕與顯示條件見 [投稿與地點按鈕盤點](BUTTON-INVENTORY.md)。

關閉投稿與設點後，已登入管理者仍顯示右上角身分及檢視模式；未登入訪客維持隱藏。這不開啟投稿或設點權限，嵌入地圖維持原有隱藏行為。
