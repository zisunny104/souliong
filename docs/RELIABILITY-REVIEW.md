# 使用流程與資料可靠性檢核

檢核使用隔離測試資料，不讀寫正式專案。以下為目前程式的行為與限制。

## 投稿中斷與復原

送出失敗後，文字、附件與設定保留在當前頁面，可手動重試。自動重試只處理 429 限流；連線中斷或逾時會提示先確認投稿結果，不自動重送。送出期間禁止重複點擊；成功的卡片不再次送出。

離開提醒：存在未送出的檔案、文字、點位標題或正在送出的項目時，重新整理／離開由瀏覽器提醒。空白卡片與全部完成的佇列不提醒。這不是草稿備份：若仍離開、分頁被系統終止或瀏覽器不提供 beforeunload 提示，內容仍可能遺失；父頁移除 iframe 也不能依賴這個提醒。

目前沒有伺服器端冪等投稿鍵。若伺服器已儲存但回應途中中斷，手動重送仍可能重複；不應宣稱已完全防重複。

## 大量資料

圖片列表已有 lazy loading；批次投稿結束後才統一重繪，避免逐筆重繪。點位與投稿資料仍整批載入，清單也沒有虛擬化。`refreshAll()` 會透過不同步驟多次呼叫 `effectiveSpots()`。

以實際 `effectiveSpots()` 函式、模擬類別顏色、無編輯紀錄／空內容的 500 與 5,000 個點位各執行 20 次，平均約 0.8ms 與 8ms。這只衡量資料整理，不包含 DOM、地圖、照片、慢網路或手機 CPU，不能當作正式站效能驗收。需要再優化時，優先量測實際資料，再考慮單次更新共用整理結果與清單分批呈現。

## 多人編輯

點位內容有 `base_rev` 版本檢查；新增點位的編號在讀寫同一鎖內產生。

專案設定表單帶入內容雜湊（`meta_revision`），在持有檔案鎖的期間核對儲存版本。若另一位管理者已儲存，回應 409，保留新設定並提示重新開啟確認。未提供表單版本的客戶端只核對請求處理開始後的競爭，不保證其畫面資料未過時。

這個保護適用專案設定表單，不表示所有後台操作已有版本防護；全站設定、圖磚與樣式包等需分別評估。

## 跨來源嵌入

Chromium 已實際測試不同來源父頁／iframe：沒有既有 Cookie 的免碼文字投稿，成功寫入隔離專案，父頁收到 `contribSubmitted`。投稿碼及投稿者憑證透過請求欄位傳入；管理者 Cookie 使用 SameSite=Lax，不應依賴跨站 iframe 的管理者登入。

測試為 localhost 與 127.0.0.1，測試瀏覽器停用 LocalNetworkAccessChecks，避免本機網路政策阻擋隔離測試；沒有修改產品或正式瀏覽器安全設定。這不驗證正式 HTTPS、代理標頭、Safari／Firefox 的儲存限制或禁止第三方儲存時的行為。若 localStorage 被禁止，投稿碼與個人偏好保存仍可能失效，需要實機評估後處理，不能放寬 Cookie 安全設定代替。

## 驗證指令

```bash
node tools/contributionuicheck.js
AXE_PATH=/path/to/axe-core/axe.min.js node tools/accessibilitycheck.js
```

測試涵蓋失敗後保留內容、手動重試、送出鎖定、離開提醒、完成後不提醒、手機／桌面與深淺色介面、跨來源免碼投稿，以及專案設定表單衝突。螢幕閱讀器與真實跨站裝置驗收仍另行進行。

## 真實地圖引擎與縮圖分級

`tools/realmapcheck.cjs` 使用實際 MapLibre 6.6.0 與前台／引擎程式，資料、PHP 設定及圖片請求均隔離。空白底圖與小型合成縮圖不代表正式圖磚或原始大圖片。測試不寫入正式專案。

390／1280px 視窗、50 個密集地點、300 張照片、200 個預覽標記：14／22／32px 級距、跨級距過渡、縮圖點擊開啟燈箱與減少動態效果設定通過；沒有 JavaScript 執行錯誤。這是桌面 Chromium 改變視窗尺寸，沒有模擬手機 CPU。

正式站 HTTPS 連線被執行環境代理政策拒絕（CONNECT 403），尚未驗證 VPS、真實圖磚或實機 Safari／Firefox。

重跑測試：準備 MapLibre 6.6.0 dist 目錄中的 `maplibre-gl.mjs`、`maplibre-gl-shared.mjs`、`maplibre-gl-worker.mjs`、`maplibre-gl.css`，再執行：

```bash
MAPLIBRE_DIST=/path/to/maplibre-6.6.0/dist node tools/realmapcheck.cjs
```

需要 PHP、Playwright 與 Chromium；必要時透過 `PLAYWRIGHT_PATH` 指定已安裝的 Playwright 套件。測試輸出分開標示功能檢查結果與密集重疊觀測，截圖儲存在 `/tmp/souliong-realmap-390.png`、`/tmp/souliong-realmap-1280.png`。

### 密集收合與畫面範圍

候選位置以矩形檢查縮圖及地點範圍；不接受碰撞候選，沒有安全位置就減少預覽。保留「＋剩餘數量」入口，完全沒有空間時恢復地點的投稿數量角標。點擊入口仍可查看所有投稿；投稿者篩選的數量包含沒有 GPS 的內容。

僅建立畫面與 96px 緩衝範圍內的投稿預覽，移出卸除、移回恢復；以引擎的實際畫面投影計算排列。拖曳期間不更換標記，moveend／resize 後重排；同一視角的重複通知不重算。

50 地點／300 照片資料、390／1280px 視窗，在縮放 13／14／16 下預覽數為 17／16／31 個，測得的矩形重疊配對均為 0。測試另確認縮放 18 可展開圖片、收合地點入口可看全部 6 則投稿、移出畫面無預覽、移回恢復，以及動畫中的 DOM 標記保留。純排列測試涵蓋 14／22／32px、一般／密集／同座標地點、避開全部地點矩形及重複計算結果穩定。

同環境測量，390px 平移平均 17.3ms、1280px 平均 23.7ms；仍是軟體 WebGL、空白底圖與合成照片，不保證正式裝置 60fps。地點標記本身沒有加入聚合，完全相同位置的地點仍可能互相遮住；排列只處理投稿預覽。正式站網路限制仍未解除。
