# 投稿與地點按鈕盤點

盤點前台瀏覽、燈箱及編輯介面；後台專案管理不在本表範圍。

## 投稿

圖片、音訊、影片與文字共用卡片操作列：連結 → 引用 → 編輯／歷史／刪除 → 授權文字。

| 操作 | 位置與適用類型 | 顯示條件 | 形式 |
| --- | --- | --- | --- |
| 複製連結 | 四種投稿卡片；圖片／影片燈箱 | share 模組開啟 | link icon，32×32 |
| 複製引用資訊 | 四種投稿卡片；圖片／影片燈箱 | 投稿紀錄（地點內容區塊除外） | quote-right icon，32×32 |
| 編輯 | 四種投稿卡片；圖片／影片燈箱 | 非嵌入，投稿者可編輯本人內容或具 edit_others | pen icon，32×32 |
| 歷史版本 | 四種投稿卡片 | 非嵌入、entryHistory 開啟、超過一個版本 | clock-rotate-left icon，32×32 |
| 刪除 | 四種投稿卡片；圖片／影片燈箱 | 非嵌入且 isMine 判定為本人投稿 | trash icon，32×32 |
| 精選 | 投稿卡片 | 非嵌入且具 manage_contrib 可操作；其他人僅顯示已精選星章 | 星章，26px 圓、20px 星；可操作者有 aria-pressed |
| 授權 | 投稿卡片與燈箱 | 有合法授權設定 | 授權 icon＋文字連結；文字有底線，icon 無底線 |
| 播放／暫停 | 聲音播放器、影片預覽與燈箱 | 對應媒體類型 | 播放器操作，與編輯操作列分開 |
| 儲存／取消、版本還原 | 投稿編輯與歷史介面 | 編輯或版本還原權限 | 保留文字，明確表示結果 |

## 地點

| 操作 | 位置 | 顯示條件 | 形式 |
| --- | --- | --- | --- |
| 導航 | 地點標題操作列 | 有導航設定及有效座標 | 導航 icon，32×32；選單保留服務名稱 |
| 調整位置／地標色／連結 | 地點標題操作列 | edit_spots 權限 | location-dot icon，32×32 |
| 編輯內容 | 地點說明操作列 | contentEdit 開啟及 edit_spots 權限 | pen icon，32×32 |
| 歷史版本 | 地點說明操作列 | 非嵌入、spotHistory 開啟、超過一個版本 | clock-rotate-left icon，32×32 |
| 複製聲音區塊連結 | 地點說明的聲音區塊 | 有區塊識別碼 | link icon，32×32 |
| 外部連結 | 地點標題操作列 | 地點有合法 links | 對應服務 icon；外部網址連結 |
| 新增／移除連結 | 地點編輯介面 | 已進入編輯 | 新增保留文字；移除 × 有無障礙名稱 |
| 儲存／取消／還原初始位置 | 地點編輯介面 | 已進入編輯 | 保留文字，避免混淆儲存與還原 |
| 移動／刪除內容區塊 | 內容編輯器 | 已進入內容編輯 | 上／下／垃圾桶 icon，附文字提示 |
| 還原內容版本 | 地點歷史介面 | edit_spots 及內容編輯器可用 | 保留文字 |

icon 操作保留 title 與 aria-label；裝飾 icon 不取代可及名稱。儲存、取消、還原等結果性操作保留文字。

## 驗證範圍

`tools/displaycheck.js` 使用隔離資料驗證圖片／音訊／影片／文字的操作排列、編輯展開、可及名稱、寬高；另檢查地點編輯／歷史按鈕、分享卡片及聲音區塊複製連結。測試涵蓋導航、授權、精選管理／訪客及歷史開關。這不是所有權限組合或所有播放器行為的完整測試。
