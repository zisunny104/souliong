# 管理權限來源

身分管理顯示既有的兩種來源，不新增身分組或繼承資料格式：

- 全站管理者：繼承所有專案的管理權限，不受專案管理功能開關影響。
- 專案管理者：專案帳號與管理 PIN 依各自授權使用；關閉專案管理功能後，這些專案授權不生效。

全站管理者名單與專案帳號名單僅提供全站管理者查看。其他管理者只會看到全站管理權限的來源說明，不會取得全站帳號名稱。

具有「授權管理」權限的專案管理者，可看到權限完全包含在自己權限範圍內的管理 PIN。比較的是實際權限集合，不是權限數量；包含未識別的已啟用權限也不會公開。將既有 PIN 轉成帳號的請求使用相同限制，不能透過直接送出請求繞過名單限制。這不會擴大原有的帳號管理權限。

驗證：`PLAYWRIGHT_PATH=/path/to/playwright node tools/identitysourcecheck.js`。測試建立並清除獨立暫存專案，檢查全站名單保密、權限子集、互不包含的權限、未知權限、轉換請求，以及 390／1280 像素寬度的來源卡片。
