# Souliong 循跡

以地圖整理與探索地方的地點、照片、影片、聲音與文字，內容可由管理者建立，也可開放投稿。資料可透過公開 API 取用，或嵌入其他網頁。

循著地方留下的痕跡，用地圖探索、記錄地方。

建立在 [KoiLiSu 開利手](https://github.com/zisunny104/koilisu-framework) 框架上。

## 功能

- 分類彩色標記地圖，深淺主題自動切換
- 可疊加的底圖與插畫圖層，附對位切圖工具
- 3D 模式：建物立體顯示，可自訂排除區域
- 投稿照片、影片、音訊、文字；點位內容區可保留歷史版本
- 投稿代碼控管誰能投稿；投稿者只能刪除自己的內容
- 批次上傳、EXIF／GPS 定位
- 匿名統計、可嵌入其他網頁
- 分層管理權限，逐專案、逐項授權
