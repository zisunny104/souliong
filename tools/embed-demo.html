嵌入 API 示範父頁

以 iframe 載入 ?embed=1&ui=bare 的地圖，透過 postMessage 送出指令並顯示所有事件。本頁的來源必須列在該專案或全站的「允許嵌入網域」，否則地圖不會回應。

連線

本頁來源（請列入允許清單）：

點位

場景指令（主要路徑）

亂序測試只用「點位」清單裡的 spotId；結束後以 getState 檢查最後一個指令的終點狀態。

低階指令

自訂訊息（JSON，會自動補上 v、ns、id）

導航小窗（api=navsheet）

用上方「點位」欄位的 spotId。小窗收起時會收到 navsheet-close，本頁隨即關閉遮罩。

尚未載入 待回覆：0 可拖曳右下角調整 iframe 大小（測試旋轉或鍵盤）
